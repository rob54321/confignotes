Disable snap install of thunderbird.

Add Mozilla team ppa
sudo add-apt-repository ppa:mozillateam/ppa
sudo apt update

Prioritise the PPA over Snap
Create a preferences file to ensure the system uses the .deb version:
sudo nano /etc/apt/preferences.d/mozillateamppa

Paste the following into the file:
Package: thunderbird*
Pin: release o=LP-PPA-mozillateam
Pin-Priority: 1001

Package: thunderbird*
Pin: release o=Ubuntu
Pin-Priority: -1

Save and exit (Ctrl+O, Enter, then Ctrl+X).

Install thunderbird 
sudo apt install thunderbird

Optional: Prevent Snap Reinstallation via Unattended Upgrades

To avoid Snap sneaking back in during automatic updates:
echo 'Unattended-Upgrade::Allowed-Origins:: "LP-PPA-mozillateam:${distro_codename}";' | sudo tee /etc/apt/apt.conf.d/51unattended-upgrades-thunderbird


Set up thunderbird with correct locale and date
format 13 July 2025 etc.

sudo apt update
sudo apt install thunderbird-locale-en



Optional: Set Locale via Terminal Launch
 You can also launch Thunderbird directly with the locale:
bash
LANG=en_ZA.UTF-8 thunderbird

Force Thunderbird to Use South African Date Format

Thunderbird sometimes defaults to US-style MM/DD/YYYY even with en-ZA,
 so you can explicitly define the format using its Config Editor:

    Open Thunderbird’s Config Editor

        Go to ≡ Menu > Settings > General

        Scroll to the bottom and click Config Editor

    Create Custom Date Format Preferences In the search box, type:
intl.date_time.pattern_override.date_short
Click the + button to add it as a String

Set the value to:
dd/MM/yyyy or dd MMM yyyy for 07 July 2025 etc

Repeat for time format:

intl.date_time.pattern_override.time_short

Set the value to

HH:mm

Restart thunderbird for changes to take place.

To fix the locale settings to English South Africa
copy the menu/internet/thunderbird icon to the task bar.
Right click on the taskbar icon and select properties.
Edit the properties command to :
 Command: env LANG=en_ZA.UTF-8 /snap/bin/thunderbird %u

 Then it is not necessary to edit thunderbird.desktop.
 
Verify Locale Availability
 You can check if en_ZA.UTF-8 is available on your system:
locale -a | grep en_ZA

f it’s missing, generate it:
sudo locale-gen en_ZA.UTF-8
sudo update-locale
