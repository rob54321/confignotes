# This list of dependences is required to build
# and run gpxsee on the raspberry pi

sudo apt update
sudo apt install build-essential cmake pkg-config \
    qtbase5-dev qttools5-dev-tools qt5-qmake \
    libqt5svg5-dev libqt5opengl5-dev \
    zlib1g-dev libpng-dev libjpeg-dev libproj-dev

sudo apt install libexif-dev libtiff-dev libgeos-dev

Runtime Dependencies

Once built, GPXSee requires the following runtime libraries
 (already covered if you installed the dev packages):

    Qt runtime (libqt5core5a, libqt5gui5, libqt5widgets5)

    Qt SVG/OpenGL runtime (libqt5svg5, libqt5opengl5)

    zlib, libpng, libjpeg for file parsing and map rendering

    proj for coordinate transformations
